# 🎓 إتقان | منصة التحضير لمباريات التعليم بالمغرب (أطر الدعم والمختصين)
### Itqan - Moroccan Education Examination Preparation Platform

منصة تعليمية تفاعلية حديثة وعصرية مبنية بـ **React + Vite + Tailwind CSS** و **Supabase SQL**، مصممة خصيصاً لمساعدة المترشحين لمباريات التعليم وأطر الدعم (مختصي الاقتصاد والإدارة، الملحقين التربويين، والملحقين الاجتماعيين) على اجتياز الاختبارات الكتابية بنجاح عبر محاكاة امتحانات حقيقية مع الشرح والتعليل القانوني المعتمد.

## ✨ المميزات الرئيسية للمنصة

- 📱 **واجهة عصرية متجاوبة بالكامل (Mobile-First & Desktop):** تصميم مريح وواضح بدون تكدس، متوافق مع كافة أحجام الهواتف الذكية والحواسيب.
- 🎯 **نظام الخطوات التدريجي (Step-by-Step Flow):**
  1. **الخطوة 1:** اختيار المسلك والتخصص.
  2. **الخطوة 2:** اختيار الامتحان المطلوب أو تفعيل وضع الاختبار العشوائي الشامل.
  3. **الخطوة 3:** تخصيص إعدادات الامتحان (زمن الاختبار، ترتيب الأسئلة، وتوقيت ظهور التعليل).
  4. **الخطوة 4:** إجراء الاختبار التفاعلي مع عداد تنازلي وشريط تقدم ذكي.
  5. **الخطوة 5:** صفحة النتائج التحليلية الدقيقة مع إمكانية مراجعة كل سؤال.
- 📚 **بنك أسئلة رسمي وشامل (412 سؤالاً رسمياً):**
  - **امتحانات 2024:** الموضوع 1 (التدبير المادي والمالي والمحاسباتي - 72 سؤالاً) + الموضوع 2 (الاختصاصات والمهام - 60 سؤالاً).
  - **امتحانات 2023:** الموضوع 1 (التدبير المادي والمالي - 80 سؤالاً) + الموضوع 2 (الاختصاصات والمهام - 60 سؤالاً).
  - **امتحانات 2022:** الموضوع 1 (التدبير المالي والمادي - 80 سؤالاً) + الموضوع 2 (الاختصاصات والمهام - 60 سؤالاً).
- ⚖️ **تعليلات وسندات تشريعية دقيقة:** كل سؤال مرفق بمرجعه القانوني المعتمد (مرسوم الصفقات العمومية، النظام الأساسي الخاص بموظفي الوزارة، المرسوم 2.02.376 لمؤسسات التعليم، القانون التنظيمي للمالية 130.13...).
- 🗄️ **قاعدة بيانات Supabase SQL متكاملة:**
  - جداول مخصصة (`specialties`، `exams`، `questions`).
  - أمان فائق عبر سياسات **Row Level Security (RLS)** تمنح صلاحيات القراءة فقط للزوار وتمنع التعديل أو المسح.
  - دالة RPC مدمجة `get_random_exam_questions(p_count)` لتوليد اختبارات عشوائية فائقة السرعة.

## 🛠️ التقنيات المستخدمة

- **Frontend:** React 19, Vite, Tailwind CSS, Lucide React (الأيقونات), Canvas-Confetti
- **Database / Backend:** PostgreSQL / Supabase SQL (RLS Security + RPC Stored Procedures)
- **Deployment:** Vercel (Edge Network) & GitHub

## 🚀 التشغيل محلياً (Local Development)

```bash
# استنساخ المشروع
git clone https://github.com/loopcoding1/itqan.git

# الدخول للمجلد
cd itqan

# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:5173`

## 🗄️ إعداد قاعدة بيانات Supabase (اختياري)

إذا أردت ربط التطبيق بقاعدة بيانات Supabase السحابية:
1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. افتح **SQL Editor**.
3. انسخ محتوى الملف `supabase/full_setup.sql` والصقه واضغط **Run**.
4. سيتم إنشاء الجداول تلقائياً وملؤها بجميع الأسئلة الـ 412 مع تأمينها بالكامل عبر RLS.

---

## 🌐 النشر على Vercel (Deployment)

تم تجهيز المشروع بملف `vercel.json` جاهز للنشر الفوري:
1. اذهب إلى [Vercel](https://vercel.com) وسجل الدخول باستخدام GitHub.
2. اضغط على **Add New Project** ثم اختر المستودع `itqan`.
3. اضغط على **Deploy** دون الحاجة لأي تعديلات إضافية!
